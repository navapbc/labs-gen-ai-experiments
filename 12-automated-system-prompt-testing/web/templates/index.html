Metrics Key

Flags

ABOVE_8TH_GRADE
Resource descriptions exceed 8th-grade reading level (Flesch-Kincaid). Target: below 8.0.
LOW_GROUNDING
Less than 70% of output resources match the reference data (RAG context). Only flagged when web search is NOT used. When web search is enabled, ungrounded resources likely came from the web and are not fabricated.
HALLUCINATION_RISK
Low grounding + no web search + more output resources than input RAG resources. Strongly suggests the LLM fabricated resources from training data rather than citing the provided references.
DUPLICATE_RESOURCE
Same organization appears more than once in the output.
BROKEN_URL
Resource URL returns a 404 or server error (requires URL Validity dimension enabled).
INVALID_JSON / EMPTY_OUTPUT
LLM output could not be parsed as valid JSON, or returned an empty result.
MISSING_CONTACT_*
Resource is missing phone number, address, or website URL.
CROSS_STATE
Resource is located outside the user's state/region (requires Location Match dimension enabled).

Grounding Thresholds

Grounding measures what % of output resources appear in the reference data (RAG context). When web search is enabled, grounding flags are suppressed since ungrounded resources likely came from web results.

High: 90%+
LLM is closely following the reference data.
Medium: 70–90%
Some resources may be from training data. Review ungrounded ones.
Low: <70%
Many fabricated resources. Triggers LOW_GROUNDING flag. Prompt may need stricter grounding instructions.

Grade Level

Flesch-Kincaid grade level of resource descriptions. Lower is simpler.

Good: ≤8.0
8th-grade reading level or below — accessible to most adults.
Flagged: >8.0
Triggers ABOVE_8TH_GRADE. Common causes: jargon, long sentences, formal vocabulary.
