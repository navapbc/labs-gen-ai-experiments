# Experiment 13 Case Study Website

This folder contains a scrollable website version of the Experiment 13 case study. It is meant for PMs, delivery teams, and AI practitioners who want the narrative version of the evaluation pipeline before reading the code.

The case study summarizes a two-track optimization approach:

- **Track 1:** model, reasoning, temperature, web search, and latency tuning.
- **Track 2:** output-quality evaluation, rubric scoring, deep review, prompt iteration, and automated improvement.

The source code for the pipeline remains in the Experiment 13 folder.
